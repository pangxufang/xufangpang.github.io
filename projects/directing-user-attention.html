Directing User Attention via Visual Flow on Web Design

Xufang Pang, Ying Cao, Rynson W.H. Lau, and Antoni B. Chan · ACM Transactions on Graphics (SIGGRAPH Asia 2016)

Abstract

We present an approach that allows web designers to direct user attention via visual flow on web designs. By collecting and analyzing users' eye-gaze data under task-driven conditions, we build attention models and an optimization framework that guides attention along a designer-specified path through an existing web design.
